Un monde familier, encore à explorer

DinoTale Tornie permet de retrouver l’aventure sur PC, avec de nouvelles façons de jouer et de créer. Cette présentation garde les découvertes intactes : elle explique comment démarrer, se repérer et conserver sa progression.

Envie de tout découvrir en jouant ? Cette page suffit pour commencer. Le contenu précis, les conditions de déblocage et les nouveautés détaillées sont regroupés dans le guide complet facultatif.

Guide complet — spoilers

Installer et démarrer

  1. Extraire le paquet completChoisir Windows x64 ou le candidat expérimental Linux x64 et conserver tout le dossier dans un emplacement autorisant l’enregistrement.
  2. Ouvrir le lanceurSous Windows, ouvrir DinoTale.exe. Sous Linux, lancer Jouer.sh ; Atelier.sh ouvre l’éditeur. Les paquets incluent l’Atelier autonome, sans installation de .NET.
  3. Sélectionner la ROM au premier lancementChoisir une ROM originale USA de Yoshi’s Story. Les formats .z64, .v64 et .n64 sont reconnus. Le contenu est préparé localement ; le fichier choisi reste inchangé.
  4. Choisir une aventureParcourir le livre DinoTale et choisir un mode disponible. Au lancement du jeu, appuyer sur Start après l’écran titre.
Aucune ROM n’est fournie et l’import ne l’envoie sur aucun serveur externe. Les archives commencent avec une progression vide et le volume à 3 %. Une ROM déjà modifiée ou d’une autre région est refusée.

Linux reste expérimental. Des retours de jeu positifs ont été reçus sur deux PC, avec Basalt et CachyOS. Linux Mint 22.3 et les autres configurations restent à valider.

Commandes et navigation

  • Entrée correspond à Start ; Échap ouvre les réglages du moteur. Configurer le clavier et les manettes dans ces réglages.
  • B dans les sélections de niveau ou de Yoshi revient au menu DinoTale.
  • Le bouton Menu principal permet de quitter Story et les crédits.
  • Atelier : Ctrl + S pour enregistrer ; Ctrl + Z / Y pour annuler/rétablir.
  • Molette : zoom ; clic droit : parcourir ; glisser : déplacer un objet ; Alt : ignorer l’aimantation.
  • F8 dans la fenêtre de test capture l’icône du niveau.

L’Atelier

Créer une copie séparée d’un niveau original, modifier ses salles et ses objets, puis essayer le résultat en jeu. L’Atelier permet aussi de réunir les créations dans une partie personnalisée.

Des outils sont prévus pour le terrain, la musique, les passages et les points d’entrée. Les objets disponibles dépendent des ressources de chaque salle. Les décors animés et les comportements se vérifient en jeu.

Sauvegardes et mises à jour

La progression se trouve dans pc/profiles/content-personal, les créations dans pc/content. Conserver le dossier de profil entier, avec ses journaux, pour déplacer une installation.

Avant une mise à jour, fermer le jeu et l’Atelier, puis sauvegarder le profil et les créations. Les paquets publics commencent avec une progression vide : ne pas remplacer un profil personnel par celui de l’archive. Une sauvegarde normale du jeu et un état instantané d’émulateur sont des formats différents.

État du projet

Le téléchargement public reste en 0.34.0-beta.1. Les travaux suivants sont en validation privée et ne font pas partie de ces archives.

Il s’agit d’une préversion. Certaines fonctions expérimentales sont incomplètes et les vérifications automatisées ne remplacent pas une partie complète. Le guide complet distingue le contenu disponible des travaux en cours.

Aide et limites connues

Statut du candidat Linux

Le candidat cible les PC Linux x64, notamment Linux Mint 22.3. Son import local et son Atelier autonome ont été vérifiés sous Ubuntu 22.04. Deux essais de la version publique sur PC, sous Basalt et CachyOS, ont été rapportés comme fonctionnels. Le matériel et l’étendue des essais ne sont pas précisés ; Mint 22.3 reste à vérifier. Les essais WSL en rendu logiciel ne permettent pas de conclure sur un vrai PC. Ce téléchargement reste expérimental.

ROM refusée

Utiliser une image originale USA de Yoshi’s Story, pas une ancienne ROM du projet déjà modifiée. Les trois ordres de fichiers N64 sont reconnus, puis l’empreinte exacte est vérifiée.

Les objets sont petits dans l’éditeur

Centrer la vue sur le point d’entrée ou utiliser la molette. Sélectionner un passage permet aussi de retrouver sa position.

Le décor n’est pas entièrement animé

L’éditeur affiche un aperçu fixe du terrain principal. Arrière-plans et objets dynamiques se vérifient dans le jeu.

Signaler un plantage

Indiquer la version, le système, le niveau, le mode, le Yoshi et les étapes. Un extrait du journal, sans chemins personnels, peut aider. Ce fichier n’est pas envoyé automatiquement.
