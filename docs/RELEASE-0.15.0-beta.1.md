# 0.15.0-beta.1

## Français

Première bêta publique de DinoTale Tornie. Le moteur Windows reprend la base 0.15.0, avec l’aperçu du terrain original et la navigation des passages dans l’Atelier. Importeur local ajouté pour reconstruire le contenu avec la ROM originale USA du joueur. Sauvegarde neuve, aucun record, achat ou monnaie personnels.

Contrôles : patch BPS reconstruit exactement ; trois ordres d’octets de ROM ; refus des fichiers incorrects ; réimport sans changement ; protection des fichiers et sauvegardes existants ; régénération des 219 fichiers natifs identique après normalisation des fins de ligne. Contrôles natifs détaillés dans le reçu de validation de cette version.

Limites : tests manuels complets encore nécessaires ; terrain en lecture seule, placements éditables ; coop et défi de boss non jouables ; Linux encore expérimental. L’interface de l’Atelier est principalement française et les textes du jeu USA restent en anglais. Les nouveaux menus du jeu et le guide proposent FR/EN.

## English

First public DinoTale Tornie beta. The Windows engine retains the 0.15.0 baseline, with original terrain preview and room passage navigation in the Workshop. A local importer reconstructs the content from the player’s original USA ROM. Fresh progression, with no personal records, purchases or currency.

Checks cover exact BPS reconstruction, all three ROM byte orders, rejection of incorrect files, idempotent import, preservation of existing content/saves, and regeneration of all 219 native files with identical normalized contents. See this version’s validation receipt for native checks.

Full manual testing is still pending. Terrain is read-only; object placements are editable. Playable co-op and the boss challenge are planned. Linux remains experimental. The Workshop UI is mainly French, original USA game text remains English, and the new game menus and guide offer French/English.
